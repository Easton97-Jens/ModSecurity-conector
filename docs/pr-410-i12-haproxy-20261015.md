## SPOP request

This route is a bounded authorization sample. The harness retains the SPOP handshake, NOTIFY/ACK frame bytes, sample tags and lengths, `req.body_size` representation, HTTP-version metadata, backend count and client result. Incomplete, missing, unknown or inconsistent sample metadata must fail closed. Unknown/chunked framing and unsupported HTTP/2 mappings remain unqualified for full inspection.

A complete request-only sample with response phases disabled reaches native allow but `common_finish` returns `-3` with completed phase mask `3`; the actual ACK is `503`, client status is `503`, and backend request count is zero. A separate combined request run reaches mask `15`, finish `0`, ACK `200` and one backend request. That request run is not counted as an independent companion qualification.

A real HTTP/2 Content-Length sample carries `http_version=2.0`, yields ACK `200` and one backend request, while the independent native audit records `HTTP/1.1`. The request-only finish mismatch and HTTP-version mismatch are reported to [#382](https://github.com/Easton97-Jens/ModSecurity-conector/pull/382#issuecomment-6194176740); neither is a product fix in this PR.

A malformed NOTIFY actually returns ACK `400` with `block=true`, client `503` and no backend request. The initial harness incorrectly expected no ACK. That attempt remains `HARNESS_DEFECT`; a source-bound offline evaluation corrects its expectation without crediting a fresh host run.

HAProxy-specific adversarial tests cover malformed frames, technical errors, reentry, timeout, TTL, cancellation and sink serialization/`fputs`/`ferror`/`fflush`/`fclose` failures at their actual test layer. Native selftests and injected sink controls establish those branches only; each host claim still needs its own transport and native evidence.

## HTX response companion

Companion probes use a separate host execution and independent MRC1 observation. They inspect correlation and transaction retention, P3 OUTCOME→RELEASE ordering before commit, P4 Safe/Strict, missing or expired correlation, cancellation and concurrent cleanup. Request ACKs cannot substitute for companion-side frame ordering, native response phases, terminal handling, client bytes or transaction release.

Missing, stale or mismatched OUTCOME data and terminal EOS/Finish/Close must be read from retained raw events. No synthetic EOS sequence is accepted. The earliest observed technical failure is preserved even when a later cancellation or close occurs. A successful harness expectation remains an observation result until the original oracle and complete lifecycle packet are reviewed.

The independent P3-deny run records MRC1 opcodes `1→2→8→7` (OUTCOME deny `403`, then RELEASE), no COMMIT/BODY/EOS, actual client `403` and one native free per transaction. The separate Safe run records `1→2→5→3→4→8→7` with `log_only`, client `200` and 33 body bytes. Expired correlation records CLAIM→RESULT error and client `503`, without invented EOS. Two Common cleanup calls with one native cleanup show idempotent cleanup; this does not establish double free. No `engine_timeout` first-cause claim is made without a physical latched error field.

Strict configuration is accepted and its host branch chooses `abort_connection`, but the measured buffered 33-byte response still reaches the client completely as HTTP `200` with TLS close after native P4 deny `403`. `companion/strict-transport-cause.json` traces `finish_companion_response` through `fail_closed_postcommit` to asynchronous `stream_shutdown`, followed by a positive `http_end` return; upstream queued output advances before the later task shutdown. A positive `SSL_write` of 210 bytes occurs after the deny and cleanup, matching client SHA-256 `9b6e9773ad3ed4e42cfc54373d5769e9d393f634124bf5667b54be2cc8ab8176`. This is a confirmed scoped implementation mismatch, not proof that Strict is unsupported and not a generalization to all traffic. The confirmed Strict finding is reported separately in [#382](https://github.com/Easton97-Jens/ModSecurity-conector/pull/382#issuecomment-6194270431).
