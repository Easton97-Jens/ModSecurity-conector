# PR #382: I09–I12 Restmatrix

**Sprache:** [English](pr-382-i09-i12-rest-matrix.md) | Deutsch

Stand: 2026-10-10. Dokumentationsbasis und geprüfter Sourcebestand: `b2622a5d6ca746485c08f4789208299a111f47c7`.

Diese manuell gepflegte Matrix enthält 56 Zeilen für 14 getrennte Routenteile, jeweils I09/I10/I11/I12. Sie übernimmt den nur lesenden, revisionsgebundenen Source-/Testpfadbestand; aufgeführte Tests wurden für diese Matrix nicht neu ausgeführt. `OPEN_REST_SCOPE` bleibt offen. `AUDIT_INCOMPLETE_NO_NEW_BUG_PROVEN` bedeutet unvollständigen Audit, nicht einen bewiesenen Bug; `SOURCE_CONFIRMED_PROPAGATION_GAP` bezeichnet die zwei getrennten I11-Sourcebefunde unten. `CURRENT_PR382_ROUTE_MATRIX_NOT_PROVEN` bezeichnet fehlenden Hostnachweis für diesen #382-Stand.

Erledigte I09f/I10e-Apache-Modulkorrekturen und andere abgehakte Teilbereiche bleiben erhalten. Der [R17-Bericht](https://github.com/Easton97-Jens/ModSecurity-conector/pull/396#issuecomment-6101794434) ist ein **Nachgelagerter NGINX-H1-Systemnachweis aus PR #396** für `2f02370b07149265841411894f1a2cf7f1e978ff`, kein Produkttest von #382 oder einem späteren Dokumentationshead. Begrenzte I12b/V08a/V09a/V10a-Referenzen stehen in der [Checkliste](pr-382-checklist.de.md). Breite I09–I12 und V08–V10 bleiben offen.

## Grenzen und getrennte nächste Schritte

Apaches void-Writer meldet Serialisierungs-/Schreib-/Close-Fehler diagnostisch, reicht jedoch keinen Sinkabschluss an den Hostaufrufer zurück. SPOP prüft das Common-Event-`fputs`/`fflush` nicht. Dies sind frisch im Source bestätigte Weitergabelücken, keine erfundenen Live-Fehler und keine wieder geöffneten Apache-Modulkorrekturen. Policy und physische Negativtests müssen vor gezielten Fixes separat festgelegt werden.

Transport-Short-Write/EAGAIN/UDS/gRPC-Abbrüche sind kein physischer Event-Log-Sink-Nachweis. Composite-Coordinator/Response-Observer sind Hilfsinfrastruktur, keine zusätzliche unabhängige verkehrsführende Route; sie ersetzen weder Companion-Endpunkt noch Hostadapter. Unverändertes lighttpd Stock nativ bleibt Diagnose/Kontrolle; gepatchtes lighttpd Strict wird nicht aus Callback-Rückgaben zum Client-Abort hochgestuft. Request-only braucht seinen tatsächlichen Response-Companion.

Diese Dokumentation führt keinen Cross-Connector-Fix oder neuen Hostlauf aus. #382 bleibt Draft; Protected, H2/H3, CRS, Off und Produktion werden nicht aus R17 abgeleitet.
