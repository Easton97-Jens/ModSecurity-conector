## Motivation and problem statement

Replacing an ancestor after validation could redirect that read. The separate pending native physical-sink product change also needs an explicit effective filter option in future fixtures.

## Acceptance criteria

Then add exactly one `events-file /task/common-events.jsonl` option to fresh native v7 launches only. Retain original oracles, sealed fixtures and runtime-evidence boundaries.

## Implementation decision and rationale

`i12_native_contracts.py` admits absolute lexical descendants of the existing external storage root. It walks each directory from an owned descriptor using `O_DIRECTORY | O_NOFOLLOW`, opens the leaf relative to the held parent with `O_NOFOLLOW | O_NONBLOCK`, verifies a regular file with `fstat`, reads that descriptor and closes all owned descriptors. It never reopens the original full input path after validation. Hash references, inventory/catalog/rule parsing and declarative fixture reads share this boundary. A deterministic test swaps a checked parent for a symlink immediately before leaf opening; the old implementation reads redirected bytes, while the new implementation retains the original directory/file identity. This local Linux harness does not create a general sandbox for other programs or paths.

The other findings use shared MIME/task/fixture/main-path constants, explicit conditional steps, a tuple prefix check, focused receive/error and backend-body helpers, a lower-case local class-value name, removal of an unused parameter and `dict.fromkeys` for immutable missing values. Independent transport facts, error order and neighbor behavior remain intact.

A separate, explicitly authorized fixture change appends the native product option to the unique historical filter directive. Missing or duplicate anchors fail before preparation. The pending product parser accepts `events-file` with one nonempty private path. The preparer creates no fake event file and emits no physical-log success receipt.
