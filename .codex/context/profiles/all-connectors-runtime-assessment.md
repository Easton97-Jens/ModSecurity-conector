# All-Connectors Runtime Readiness Assessment Profile

## Command execution

Load `../command-execution-policy.md` before issuing local shell/project commands.

Run `connector-runtime-assessment.md` independently for the six host families while retaining all ten logical profile identities.

Assess at least the selected core route for Apache, NGINX, HAProxy, Envoy, Traefik, and lighttpd. Assess companion/compatibility logical profiles separately when the request or repository claim includes them.

Use one parent run with connector/profile children. Sequence host/runtime work unless isolation of ports, roots, caches, processes, evidence, and resource budgets is proven.

The final report must show which profiles reached build, config, start, traffic, P1/P2/P3/P4, recovery, cleanup, and validated evidence. No host-family aggregate may hide a weaker sibling profile.
