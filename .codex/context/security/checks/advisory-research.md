# Advisory Seed Research

When network/policy permits, identify current official advisories for the actually used host, connector/upstream origin, libmodsecurity, language/runtime, crypto/regex/parser libraries, and other selected dependencies.

Record advisory identifier/source, affected versions/conditions, local version/revision, candidate local files/functions, applicability evidence, strongest counterevidence, and local validation plan.

Use advisories only as regression seeds. Do not mark a vulnerability applicable solely because a version string appears in a range.
