# Resource Exhaustion and DoS Check

Inventory bounded resources: request/response body bytes, headers, parser depth, regex work, streams, connections, transactions, queues, goroutines/threads, file descriptors, sockets, temporary files, logs/evidence, caches, buffers, frame counts/sizes, retries, redirects, and timeouts.

For each resource record owner, configured/implementation limit, accounting boundary, attacker cost, amplification, behavior at limit, cleanup, recovery, fail-open/fail-closed outcome, and observed or source-supported residual risk.

Use bounded local load only. Respect `resources-and-storage.md` and host isolation.
