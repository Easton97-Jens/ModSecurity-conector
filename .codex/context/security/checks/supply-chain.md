# Dependency and Supply-Chain Check

Inventory actual host, compiler/toolchain, libmodsecurity, language modules/packages, protocol/parser libraries, build helpers, downloaded sources, GitHub Actions, container/images, and analysis tools used by the selected scope.

Verify current version/revision, source/provenance, pin/lock, hashes/signatures where the project contract uses them, archive/extraction safety, license/provenance requirements, ABI/API compatibility, cache/artifact isolation, workflow permissions, and absence of silent system-binary fallback.

A newer release or advisory is a seed, not proof of local impact.
